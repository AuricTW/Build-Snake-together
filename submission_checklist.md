# Lab 03 Snake Trio Submission Checklist

- [ ] Trio has exactly three registered members.
- [ ] `GROUP_CONTRACT.md` is complete and signed.
- [ ] `evidence/FUNCTION_CONTRACTS.md` contains four contracts and boundary examples.
- [ ] All public tests and at least three trio-designed tests pass.
- [ ] `evidence/DEBUG_LOG.md` records one genuine red-to-green repair.
- [ ] `evidence/TRIO_LOG.md` shows role rotation.
- [ ] `AI_USE.md` records L1 use or states `No AI used.`
- [ ] The game launches, accepts keyboard input, grows, ends, and restarts.
- [ ] Every member authored at least one Pull Request and reviewed at least one.
- [ ] GitHub Actions is green on the final commit.
- [ ] `git status --short` is empty.
- [ ] Moodle submission includes repository URL, final commit, three Pull Request URLs, and evidence files.
